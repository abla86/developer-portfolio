# Home Assistant — AB Smart Home

Home Assistant is the actual smart-home system. The portfolio only documents it.

## Dashboards
01 Nexus Mission Control · 02 Residence Climate & Energy · 03 EvoHaus Security & Media · 04 Energy Intelligence · 05 Device Health · 06 Security & Surveillance

## Safety
- No secrets in Git; use local secrets.yaml.
- Validate configuration before restart.
- Critical actions are explicit and use safe fallbacks.
- Automations are designed to avoid notification spam.
- Dashboards use real HA entities, not static portfolio mock data.

## Functions
Presence, away/night/guest modes, lighting, climate, energy, door-lock/security, leak/frost alerts, battery/device health, vacuum, media, maintenance and backup monitoring.
