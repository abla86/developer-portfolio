    02 · HOW THE PARTS FIT

    Not one fake mega-app — one coherent engineering progression

    The repositories stay separate. The showcase demonstrates the reusable concepts they collectively represent, then points back to the source projects.

    1
    InputButtons, forms, keyboard actions and user events enter the application.
    2
    StateTasks, selected dates, calculator values and current time are represented as application state.
    3
    LogicValidation, calculation, filtering, persistence and rendering rules transform the state.
    4
    UIThe result is presented through focused components instead of isolated code fragments.
    5
    VerificationThe source repositories provide the real implementation, tests, CI and documentation for each project.
    Why this matters: the small projects demonstrate the same basic engineering cycle that scales into the larger portfolio systems: input → state → logic → data → verification → user-facing result.
