Workforce & Competence Management

React · .NET 10 · EF Core 10 · SQL Server

Full-stack workforce-planning system combining shift planning, competence management and staffing coverage with explainable decision support. The local stack has now passed end-to-end verification.

  • Shift planning: create shifts, define minimum staffing, assign employees and manage competence requirements
  • Competence: catalogue, employee competence records, Basic/Intermediate/Advanced levels and validity/expiry tracking
  • Staffing: automatic minimum-staffing and competence-coverage evaluation
  • GREEN / YELLOW / RED: operational status with human-readable gap explanations
  • Candidate ranking, availability checks, absence, overlap and rest-period warnings
  • Non-destructive what-if scenario analysis and replacement suggestions
  • Authenticated data import/export, JSON backup and shift-plan sharing
  • 18/18 backend tests passed
  • EF model/migration validation passed with no pending model changes
  • Frontend lint/build, Docker, SQL Server, API and frontend health all passed
Employee + competence ↓ Shift plan + staffing requirements ↓ Coverage engine ↓ GREEN / YELLOW / RED ↓ Gap explanation + candidate planning
