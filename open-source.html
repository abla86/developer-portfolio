Contribution workflow

  1. Reproduce: verify the current behavior on the supported development version.
  2. Scope: select one issue and keep the patch narrow.
  3. Implement: add the smallest maintainable change, not a portfolio-specific abstraction.
  4. Verify: add or update tests, run the project's lint/type/build checks and document the result.
  5. Submit: open the PR against the repository's contribution rules and reference the issue.
  6. Record: once a real PR exists, add the PR URL to this portfolio as evidence. Do not mark an issue as completed before it is actually merged.
